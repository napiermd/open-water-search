How the audit works

Reach counts each distinct in-water track once per window. A person can appear in multiple windows. Empty openings hit no labeled track. Repeats hit a track already reached in that window. Identity switches are counted across each card’s opening and follow-up pins.

This archive shows opening records across all 129 windows. The flight 0014 case shows two openings with frame images. Use the source recording filename shown in each opening to find the original video in the MOBDrone dataset (Cafarelli et al., 2022).

The archive overlaps development, the setting grades were assigned retrospectively, and dispatch was simulated. The intervals resample recording families with both queues kept together.

The offline verifier checks every opening against independent sealed evidence and recomputes the counts and intervals from the same records this page uses. Extract the download and run python3 -I verify.py. Open the replay records.
