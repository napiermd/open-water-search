# Compare Ember with a trained detector, including on footage the detector never saw

SeaDronesSee is a standard benchmark, and free detectors trained on it already exist, so "why not use one?" is the first question a judge will ask. We will run a published SeaDronesSee-trained YOLO detector on the Mac at no cost. Both tests use the same photos and the same scoring rule as Ember. The first is the SeaDronesSee validation split, where we expect the detector to win and will say so. The second is a sample of frames from MOBDrone, a separate man-overboard dataset the detector never trained on.
