# Cap all new Ember spending at $3.00, Ember only

Going over the $10 event credit disqualifies the entry, and $9.85 was left on November 24. Every run after that date draws from one $3.00 total. Each run has its own smaller cap inside that total and stops itself before a request could cross it. The event requires every project to run on Muse Ember, so the tool uses no other Meta model, even though Meta's docs suggest pairing Ember with a larger planning model.
