# Submit a search tool backed by the 30-frame comparison

The submission is a tool a drone team points at a batch of frames. Ember takes one overview of each frame, chooses which tiles get a close look within a fixed budget, and returns a reviewer queue and a coverage map. The pitch leads with scale: at one frame per second a drone produces 3,600 frames an hour, swimmers are about 11 pixels across in a typical overview, and nobody can scrutinize every frame. The matched-spend comparison against the fixed grid serves as evidence that the cheap search does not skip people. We considered submitting the benchmark alone or a reviewer-to-boat handoff tool. A benchmark alone reads as a standalone image analyzer, which the participant guide discourages. A handoff tool would need dispatch and boat connections we cannot build or test.
