# The command is the only paid entry point

November 27, 2026. Paid Ember calls go only through `probe/open_water_search.py`, which checks one project ledger before every run and refuses a run whose worst-case cost exceeds what remains of the grant. The earlier experiment runners replay their saved answers and make no live calls. One ledger is the only way a per-run cap also guarantees the project total, and replaying keeps every published experiment reproducible at $0.
