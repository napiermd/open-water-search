# A flight is the unit of work

The event's guide lists image analyzers among the projects to avoid. The tool therefore takes a whole flight, as a video or a folder of photos in time order, and returns a search record: possible people merged across consecutive seconds, a coverage timeline, and a handoff message for each possible person. There is no single-photo mode in the demo. Ember's seeing is still image understanding. What separates the project is that it decides where to look across a flight and hands over what was and wasn't searched.
