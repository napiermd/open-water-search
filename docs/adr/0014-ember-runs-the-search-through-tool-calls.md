# Ember runs the search through tool calls, as an option

Ember receives each overview with three tools: look closer at a tile, report a sighting, and move to the next frame. It decides how many close looks each frame deserves from one budget for the whole flight. This is tool calling, the work Meta describes Ember as built for. It was to replace the fixed two-look schedule only if it won on the same 30 validation photos at equal spend.

It did not. At $0.0192 the fixed method found 79 of 134 swimmers with 13 false marks, and agent mode found 54 with 11. Each tool-calling step resends the frame's conversation and tool definitions, so the same money bought 51 calls instead of 90. The fixed method stays the default and agent mode ships behind `--mode agent`.
