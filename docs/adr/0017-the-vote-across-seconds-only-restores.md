# The vote across seconds only restores

November 24, 2026. Ember's check dismisses about one real person in nine, and it gives each second of a flight its own verdict. The same person shows up second after second, so the verdicts on one track can outvote a single wrong one. On the live clip a vote brought back 7 to 10 of the dismissed appearances with no new false alarm.

The vote can bring back a flag Ember dismissed and never removes a flag Ember kept. A dismissed flag is restored when most of Ember's verdicts on its track within three seconds either side are yes. A tie stays dismissed, and a flag seen in only one second keeps Ember's verdict. Flags are linked by the rule the search record already uses for possible people.

Restoring only was chosen for the rescue crew. Ember's yes still alerts in the second it is given. A two-way vote would hold every alert back three seconds, and it could outvote the one clear sighting of a person who is mostly under water. The cost is that the vote removes no false alarms, and a restored person appears up to three seconds late. The score counts that delay, and tests report the two-way vote as a side number from the same calls.
